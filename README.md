# Horta Automática

Projeto de TCC - Ensino Médio Integrado com Técnico em Mecatrônica (2021)

## Descrição

Sistema de automação e monitoramento para cultivo com irrigação automática em tempo real. Integra sensores de temperatura, umidade do ar e umidade do solo com interface web para visualização e controle remoto dos dispositivos.

## Componentes

- **Hardware**: ESP32, sensores DHT22, sensor capacitivo de solo, relé para controle
- **Backend**: Firebase Realtime Database
- **Frontend**: Interface web responsiva com Bootstrap


## Funcionalidades

- Monitoramento de temperatura e umidade em tempo real
- Sensor de umidade do solo com callback automático
- Irrigação automatizada via relés
- Dashboard web com Firebase
- Sincronização remota de dados

## Tecnologias

- Arduino/ESP32
- Firebase
- JavaScript, HTML, CSS
- Bootstrap
